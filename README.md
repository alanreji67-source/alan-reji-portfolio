# Alan Reji Portfolio

A simple static portfolio: only `index.html` and `style.css`. No Node.js, no build step.

- Preview: double-click `index.html` to open it in your browser.
- Edit text: open `index.html` in VS Code and change the content.
- Edit colors: change the values at the top of `style.css`.
- Host: GitHub Pages (Settings > Pages > Deploy from branch `main`, folder `/ (root)`).
